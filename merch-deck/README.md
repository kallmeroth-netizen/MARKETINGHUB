# Merch deck photos

Drop competitor product photos in this folder using the exact filenames below and
they replace the dashed placeholders in `neighborly-merch-deck.html` automatically.
Any file that is missing keeps showing its placeholder, so partial sets are fine.

| `sunlife-totes.jpg`      | SunLife city totes (Austin / Miami / Chicago / USC)        |
